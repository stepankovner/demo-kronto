# Лендинг Kronto

Одностраничный статический сайт: HTML + CSS + JavaScript без фреймворков и сборки.
Внешних запросов нет: шрифты, иконки и картинки лежат в проекте.

## Как открыть локально

```bash
cd kronto-landing
python3 -m http.server 8000
```

Откройте http://localhost:8000. Открывать `index.html` двойным кликом не получится: JS-модули и шрифты работают только через сервер.

## Где что править

| Что | Где |
|---|---|
| Все тексты страницы | `index.html`. Секции подписаны комментариями `5.1 Шапка`, `5.2 Первый экран` и т. д. |
| Вопросы, ответы и документы демо | `assets/js/demo-data.js` (формат описан в начале файла) |
| Константы калькулятора (21 рабочий день, 50%, 168 ч) | начало `assets/js/calculator.js` |
| Значения полей калькулятора по умолчанию и диапазоны | `index.html`, секция `5.10`: атрибуты `value`, `min`, `max`, `step` у пары полей (число + ползунок). Результат по умолчанию тоже прописан в HTML, чтобы он был виден без JS |
| Цвета, шрифты, размеры | `assets/css/tokens.css` |
| Стили секций | `assets/css/sections.css` |
| Вопросы по отделам (вкладки «Для кого») | `index.html`, секция `5.7` |
| Сноски к источникам | `index.html`, подвал, блок `источники` |

**Типографика.** Кавычки «ёлочки», длинное тире —, буква «ё». Перед тире и после коротких предлогов ставьте `&nbsp;`, иначе они окажутся в начале или конце строки. В `demo-data.js` неразрывные пробелы расставляются автоматически.

**Скрыть тарифы.** Добавьте атрибут `hidden` в тег секции: `<section class="section" id="pricing" hidden ...>`. Пункт «Тарифы» в меню скроется сам.

**Обновить CSS/JS/картинки после публикации.** Сервер кэширует `/assets/` на год. После правки увеличьте версию в ссылках в `index.html` (и в `404.html`, если меняли CSS): `?v=1` → `?v=2`. Иначе посетители увидят старую версию.

**Фото команды.** Сейчас вместо фото стоят заглушки с инициалами (`<span class="person__photo">`). Чтобы поставить фото, положите `assets/img/имя.webp` (квадрат 208×208) и замените заглушку на
`<img class="person__photo" src="assets/img/имя.webp" width="104" height="104" alt="">`.

## Что заполнить перед публикацией

Поиск по `[` в файлах находит все плейсхолдеры.

**Домен:** заполнен — `krontoai.ru` (в `index.html`, `robots.txt`, `sitemap.xml`, `deploy/nginx.conf`, `CNAME`). Публикация — GitHub Pages, см. `DEPLOY.md`.

Когда домен появится, замените его во всех файлах одной командой из корня проекта (подставьте свой домен вместо `example.ru`):

```bash
grep -rl '\[домен\]' index.html robots.txt sitemap.xml deploy/nginx.conf | xargs sed -i '' 's/\[домен\]/example.ru/g'
```

На Linux — то же самое, но `sed -i` без `''`. После этого в `robots.txt` уберите `#` перед строкой `Sitemap:` и проверьте, что в `sitemap.xml` стоит актуальная дата в `lastmod`.

**Контакты:** заполнены — `info@krontoai.ru` и `https://t.me/stukalich`. Встречаются в трёх местах `index.html`: блок контактов в секции «Пилот», сообщение после отправки формы, подвал. При смене правьте и текст ссылки, и адрес в `href`.

## Юридическое: форма заявки

Сейчас форма **никуда не отправляет данные**: после нажатия пользователь видит сообщение, что это демо, и прямые контакты. Поэтому чекбокса согласия нет.

> ⚠️ **Если форму подключат к реальной отправке, то до публикации нужны политика обработки персональных данных и чекбокс согласия на обработку ПДн (152-ФЗ).** Логика формы — `assets/js/form.js`.

## Аналитика

Яндекс Метрика не подключена. В `<head>` в `index.html` оставлен закомментированный блок с `TODO`. Код счётчика нужно вынести в отдельный файл: inline-скрипты запрещены политикой безопасности (CSP) в `deploy/nginx.conf`. Туда же нужно добавить домен Метрики.

## Структура

```
index.html, 404.html       страницы
robots.txt, sitemap.xml    для поисковиков
assets/css/                tokens.css → base.css → sections.css
assets/js/                 main.js (меню, вкладки), demo.js + demo-data.js (демо и окно в hero),
                           calculator.js, form.js
assets/fonts/              Onest (400–500) и JetBrains Mono (400), woff2, латиница + кириллица, лицензии OFL
assets/img/                favicon.svg, apple-touch-icon.png, og-image.png (превью для Telegram)
deploy/                    nginx.conf, kronto-site.conf, deploy.sh (вариант со своим сервером)
CNAME, .github/workflows/  публикация на GitHub Pages
```

Иконки перерисованы по мотивам набора Lucide (лицензия ISC) и встроены в `index.html` как SVG-спрайт.
