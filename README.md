# Лендинг kronto — krontoai.ru

Одностраничный статический сайт о продукте для потенциальных клиентов: HTML + CSS + JavaScript без фреймворков и сборки. Шрифты, иконки и картинки лежат в проекте; единственный внешний запрос — отправка формы записи на созвон в API kronto.

Дизайн — макет «Site v8» (хвойный, ночной синий, крем; маяк на первом экране). Тексты и факты о продукте — из репозитория `corp-ed` (главная, тарифы, безопасность).

## Как открыть локально

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Двойным кликом по `index.html` не откроется: JS-модули и шрифты работают только через сервер. Форма локально покажет «не получилось связаться с сервером записи» — API пускает запросы только с krontoai.ru (CORS).

## Где что править

| Что | Где |
|---|---|
| Тексты страницы | `index.html`, секции подписаны комментариями (`Шапка`, `01 Проблема` … `08 Созвон`) |
| Подробности тарифов (обратная сторона карточек) | `index.html`, секция `06 Тарифы`, блоки `plan__back`. Цены и состав — как в `corp-ed/frontend/src/lib/tariffs.ts` |
| Окно «Безопасность и данные» | `index.html`, `<dialog id="security-dialog">` в конце страницы |
| Вопросы, ответы и документы демо | `assets/js/demo-data.js` (формат — в начале файла). `keywords` — по ним свой вопрос узнаётся как один из готовых |
| Адрес API записи, контакты | `assets/js/config.js` |
| Политика обработки персональных данных | `privacy.html` |
| Цвета, шрифты, размеры | `assets/css/tokens.css` |
| Стили секций | `assets/css/sections.css` |
| Иллюстрации (маяк, волны, линии) | `assets/js/art.js` |

**Типографика.** Кавычки «ёлочки», длинное тире —, буква «ё». Перед тире и после коротких предлогов — `&nbsp;`, иначе они окажутся в начале или конце строки. В демо (`demo-data.js`) неразрывные пробелы расставляются автоматически (`assets/js/typo.js`).

**Обновить CSS/JS после публикации.** Увеличьте `?v=` в ссылках в `<head>` (`index.html`, `privacy.html`, `404.html`). GitHub Pages кэширует файлы на 10 минут; на своём nginx (`deploy/`) — на год, тогда меняйте и имя файла, который импортируется из модуля (`demo-data.js`, `config.js`, `typo.js`).

## Запись на созвон

Форма (`assets/js/form.js`) собирает имя, телефон, компанию, число сотрудников за компьютером, тариф, удобные **день и окно времени** и согласие на обработку данных.

- Дни и окна приходят из API (`GET /api/v1/leads/form`): будни, с завтрашнего дня на 30 дней вперёд, окна 10–12, 12–14, 14–16, 16–18 по Москве. Посетителю не из Москвы под окном показывается его местное время.
- Заявка уходит в `POST /api/v1/leads` бэкенда `corp-ed`. Там она сохраняется (180 дней), команде приходит **письмо с контактами** на `LEADS_NOTIFY_EMAIL` и **сообщение в Telegram** без персональных данных (тариф, места, время).
- Кнопка «Обсудить тариф» на обороте карточки тарифа сразу выбирает этот тариф в форме.
- Если API недоступен или запись выключена, форма не теряет заявку: предлагает отправить её письмом (данные подставляются в письмо) или написать в Telegram.
- Защита от ботов — скрытое поле-ловушка и лимиты по IP на стороне API.

### Что включить на сервере API (один раз)

В `.env` стенда (`/opt/kronto/.env`, подробно — `corp-ed/docs/STAGE.md`, раздел 6):

```
LEADS_ENABLED=true
LEADS_POLICY_URL=https://krontoai.ru/privacy
LEADS_POLICY_VERSION=2026-10-06
LEADS_NOTIFY_EMAIL=info@krontoai.ru
CORS_ALLOWED_ORIGINS=https://krontoai.ru,https://www.krontoai.ru
TEAM_NOTIFY_TELEGRAM_BOT_TOKEN=…   # бот от @BotFather
TEAM_NOTIFY_TELEGRAM_CHAT_ID=…     # чат команды
```

Письма отправляет почтовый сервис стенда (`MAIL_BACKEND=postbox`, уже настроен). Проверка: `curl -s https://stage.krontoai.ru/api/v1/leads/form` отдаёт `"enabled":true`. Новые заявки — письмом и в `cli leads list`.

**Версия политики.** `LEADS_POLICY_VERSION` должна совпадать с версией в `privacy.html` (строка «Редакция от … (версия …)»). Поменяли текст политики — новая дата в обоих местах, иначе API ответит «Политика обработки данных обновилась».

**Переезд API.** Когда появится боевой сервер, поменяйте адрес в `assets/js/config.js` (`API_BASE`) и в CSP: `<meta http-equiv="Content-Security-Policy">` в `index.html` и `deploy/kronto-site.conf`.

## Что заполнить

- [ ] `privacy.html`, раздел 1 — ФИО, ИНН и ОГРНИП оператора (место помечено комментарием `ЗАМЕНИТЬ`). После правки — новая версия политики (см. выше).
- [ ] Яндекс Метрика не подключена. Код счётчика — отдельным файлом (`assets/js/metrika.js`): inline-скрипты запрещены CSP. Добавьте `https://mc.yandex.ru` в `script-src`, `img-src` и `connect-src` (meta в `index.html` и `deploy/kronto-site.conf`) и упомяните счётчик в политике.

## Иллюстрации и скорость

- Маяк и волны рисуются шейдерами в **одном** WebGL-контексте на всю страницу и копируются в обычный `<canvas>` элемента. Волны рисуются один раз, когда секция подходит к экрану, и заново — только при заметном изменении размера. Анимаций в фоне нет: страница не грузит процессор, пока её читают.
- Без WebGL (старое устройство, отключено в браузере) остаётся спокойный градиент — вёрстка не ломается.
- Линии на фоне секций — SVG, считаются при загрузке и изменении размера.
- Движения (переворот карточки, раскрытие ответов, плавная прокрутка) выключаются, если в системе включено «уменьшить движение».
